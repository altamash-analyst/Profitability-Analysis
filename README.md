# Financial Calculation Framework

The project uses a structured profitability calculation approach.

### Sales Revenue

```text
Sales Revenue = Gross Revenue - Discount Amount
````

### Gross Profit

```text
Gross Profit = Sales Revenue - COGS
```

### Gross Margin

```text
Gross Margin % = Gross Profit / Sales Revenue
```

### Net Profit

```text
Net Profit = Gross Profit - Shipping Cost
```

### Net Profit Margin

```text
Net Profit Margin % = Net Profit / Sales Revenue
```

### Profit Per Unit

```text
Profit Per Unit = Net Profit / Units Sold
```

These calculations were implemented and visualized using Power BI and DAX.
